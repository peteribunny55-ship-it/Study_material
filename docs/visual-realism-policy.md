# Visual realism policy

This project follows the user's requirement to avoid toy-like, low-poly or cartoon-style imagery.

## Rules

- No low-poly placeholder characters are treated as final art.
- No primitive capsule, box or sphere characters are used as final player models.
- The project should visually resemble a live professional cricket broadcast rather than a video game cartoon.
- If photorealistic assets are not yet available, the project must clearly preserve the realistic sports-broadcast direction rather than pretending the temporary placeholders are final.
- Any future asset integration must use realistic scanned or authored 3D models, physically based materials, and broadcast-grade lighting.

This policy is intended as a quality guardrail for future milestone work and content creation.
